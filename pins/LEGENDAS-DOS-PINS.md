# Legendas dos 10 pins

Para cada imagem, use o **título**, a **descrição** e o **link** abaixo. Publique
1 pin por dia (ou agende os 10 de uma vez pelo Pinterest).

Ao criar o pin no Pinterest:
1. "Criar Pin" → arraste a imagem
2. **Título**: cole o título
3. **Descrição**: cole a descrição
4. **Link de destino**: cole o link
5. **Pasta**: escolha a indicada
6. Publicar (ou "Agendar" para uma data futura)
